# Telegram Media Bot

Telegram-бот для зберігання фото та відео осмосів. Файли залишаються в Telegram; у SQLite зберігаються їхні `file_id`, щоб бот міг повторно надіслати медіа під час перегляду.

## Можливості

- ручне введення унікального ID осмосу у форматі `60xxx`;
- сценарій створення: ID, розмір (`250`/`500`/`750`), тип `Full`/`Light`, необов'язкові фото/відео та коментар;
- ролі власника, адміністратора, редактора медіа та переглядача; невідомим користувачам доступ заборонено;
- інтерактивний список користувачів для власника й адміністратора: зміна ролі або видалення;
- повне редагування осмосу: зміна ID і типу, додавання/заміна/очищення медіа, зміна коментаря або видалення з підтвердженням;
- список осмосів, відсортований за ID, по 10 на сторінку; вибір ID показує тип, коментар і всі збережені медіафайли;
- «Назад» повертає до попереднього кроку; перед втратою незбережених даних бот просить підтвердження;
- автоматична міграція схеми SQLite зі збереженням наявних даних.

## Вимоги

- Python 3.11 або новіший;
- токен Telegram-бота від [@BotFather](https://t.me/BotFather);
- числовий Telegram ID власника;
- вихідний HTTPS-доступ до Telegram.

## Налаштування та запуск

```bash
python -m venv .venv
# Windows PowerShell:
# .\.venv\Scripts\python.exe -m pip install -r requirements.txt
# Linux:
# source .venv/bin/activate
pip install -r requirements.txt
```

Створіть `.env` на основі `.env.example`:

```ini
BOT_TOKEN=your-telegram-bot-token
OWNER_TELEGRAM_ID=123456789
DATABASE_PATH=media_bot.sqlite3
```

Запуск:

```bash
python -m app.bot
```

Одночасно може працювати лише один процес polling для токена бота. Зупиніть інші локальні чи серверні копії, інакше Telegram поверне `TelegramConflictError`.

## Команди

- `/start` — показати роль і головне меню;
- `/new` — створити осмос;
- `/add 60123` — додати фото або відео до наявного осмосу;
- `/get 60123` — переглянути осмос і медіа;
- `/comment 60123` — змінити коментар;
- `/cancel` — попросити підтвердження виходу з активного сценарію.

Власник і адміністратор керують користувачами через **Керувати користувачами**. Щоб додати користувача, надішліть контактом окреме повідомлення; надсилання власного контакту відхиляється.

## Розгортання та дані

Не додавайте до Git `.env`, `.venv`, Python-кеші чи `media_bot.sqlite3`. База SQLite містить користувачів, осмоси й посилання на медіа; резервну копію або перенесення бази виконуйте окремо, якщо потрібно зберегти ці дані. На Linux-сервері створюйте `.venv` безпосередньо на сервері, а не копіюйте Windows-середовище.
