# Telegram Media Bot

Telegram-бот для організації фото й відео у групи. Медіа не завантажується на сервер: у SQLite зберігається Telegram `file_id`, тому під час пошуку бот повторно надсилає файл через Telegram API.

## Можливості

- унікальний ID групи у форматі `60xxx` (`60000`–`60999`);
- створення групи з коментарем;
- додавання фото та відео до групи;
- зміна коментаря;
- пошук групи за ID з виведенням коментаря та всіх медіа;
- FSM-стани для безпечного діалогу та валідація вхідних даних.

## Запуск

Потрібен Python 3.11 або новіший і токен бота від [@BotFather](https://t.me/BotFather).

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env
```

Відредагуйте `.env` і запустіть:

```bash
python -m app.bot
```

## Команди

- `/new` — створити групу, після чого ввести коментар або `/skip`;
- `/add 60123` — почати додавання фото/відео до групи;
- `/comment 60123` — змінити коментар;
- `/get 60123` — показати опис і всі збережені медіа;
- `/cancel` — скасувати активний діалог.

Після `/start` бот показує клавіатуру з цими діями. Кнопки працюють і в приватному чаті з ботом: натисніть **Додати медіа**, **Знайти групу** або іншу дію та дотримуйтесь підказок. Щоб передати бота іншій людині, надішліть їй його Telegram-посилання або username, отриманий у @BotFather.
